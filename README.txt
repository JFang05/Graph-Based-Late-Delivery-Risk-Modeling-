Team 015 Final Project
Predicting Systemic Delivery Risk in Supply Chains: A Graph Attention Network Approach

Algorithm
   DESCRIPTION
   This project predicts delivery risk in an e-commerce supply chain using both traditional tabular machine learning models and graph-based neural network models. The final implementation uses the Brazilian E-Commerce Public Dataset by Olist and compares Random Forest, XGBoost, and MLP against GCN, GNN, and GAT models.

   The project code was consolidated into a final Jupyter notebook so the complete workflow can be run in one place. The notebook, team015_final_notebook.ipynb, is organized to be run in order and includes data loading, preprocessing, feature engineering, graph construction, model training, evaluation, and visualization. Earlier experimental cells, duplicate code, and outdated dataset-specific logic were removed so that the final package reflects only the final project pipeline.

   The file team015_final_notebook.ipynb serves as the project reference implementation and should be used to reproduce the final results reported in the paper.

   The consolidated notebook includes evaluation for:
   Random Forest
   XGBoost
   MLP
   GCN
   GNN
   GAT

Visualization
   DESCRIPTION
   Our visualization is a dashboard built in TypeScript with D3 and React, tailored to explore e-commerce connections and delivery patterns. It features three innovative and intuitive components: a Map, a Delivery Timeline, and a Visual Model Representation. The system relies on a drill-down approach to balance aggregation and granularity, allowing users to adjust the visualization to suit their desired level of detail.

   The primary component is the Map, which illustrates the primary innovation offered by our Graph Neural Network (GNN) model: associating orders related by location and time. To prevent visual clustering, it uses a three-level hierarchy (location, customer/seller, and order). It includes a weekly time range slider and allows filtering by customer/seller view and delivery outcomes (on time/late). The second component is the Delivery Timeline, a Gantt Chart that splits orders into phases to help stakeholders quickly identify bottlenecks leading to delays. Finally, the Visual Model Representation illustrates how our predictive model works under the hood by plotting an order and its k-nearest neighbors (k=5) based on customer location and temporal proximity.

   Otherwise, follow the instructions below to run it yourself.

   INSTALLATION
   1. Ensure you have Node.js and npm installed on your system.
   2. Open a terminal and navigate to the "viz" directory
      $ cd viz
   3. Install the required JavaScript dependencies (React, D3, Vite, etc.) by running:
      $ npm install

   EXECUTION
   1. After the installation is complete, start the local development server by running:
      $ npm run dev
   2. In your terminal, you will see a local URL generated by Vite (typically http://localhost:5173/). 
   3. Open your preferred web browser and navigate to that URL to interact with the dashboard.
   4. Alternatively, you can build and preview the production-ready application by running:
      $ npm run build
      $ npm run preview
